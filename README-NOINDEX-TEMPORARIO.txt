FESTAS BY VALKIRIA — NOINDEX TEMPORÁRIO

Esta versão impede temporariamente a indexação no Google enquanto o site
ainda está sendo finalizado.

Foi aplicado:
- <meta name="robots" content="noindex, nofollow"> no index.html
- X-Robots-Tag: noindex, nofollow no _headers do Netlify

IMPORTANTE:
Quando o site estiver pronto para ir ao Google, remover os dois bloqueios
e voltar o meta robots para: index, follow.

Não bloquear o Google pelo robots.txt durante esta fase, pois o Google
precisa conseguir acessar a página para ler o noindex.
